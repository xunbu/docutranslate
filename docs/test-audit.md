# 测试与问题检查记录

检查范围：当前工作区的 Python 测试、前端编码与参数测试、MinerU 在线及本地 2.x/3.x/4.x 协议、自动工作流、缓存与随包资源。

## 验证结果

- Python：310 项通过。执行命令为 `python -m pytest tests -o addopts= -p no:cacheprovider --cov=docutranslate -q`。
- 前端：13 项通过。命令：在 `frontend` 目录执行 `npm test`。
- 前端生产构建通过，发布静态资源已更新；Vite 仍提示部分 JS 包超过 500 kB，可后续优化加载体积。
- Python 全项目行覆盖率约 44%；在线 MinerU 81%、本地兼容转换器 86%、V1 协议 92%、转换缓存 100%。不能据此认定整个项目没有潜在问题。
- 协议回归测试使用模拟响应；在线 MinerU 与 DeepSeek 已做一次小样本真实调用，本地 MinerU 服务未连接。
- 146 个 Python 源文件已完成语法解析；SDK 的 TXT、Markdown、JSON、SRT、HTML、CSV、ASS、Markdown ZIP 在跳过模型调用的条件下完成实际解析与导出检查。

## 已修复并增加回归测试

| 问题 | 修复 |
| --- | --- |
| 前端将结束页 0 当成空值，变为解析到末页 | 区分合法的 0 与无法解析的空值 |
| 本地解析缓存未区分服务地址和账户 | 缓存键加入服务地址和密钥摘要 |
| 缓存超过配置容量，读取后不更新淘汰顺序 | 严格限制容量、实现 LRU、支持容量 0，并对读写加锁 |
| 部分图片扩展名未识别，自动模式可能将图片/PDF 交给文本转换器 | SDK 与 HTTP 共用解析格式集合，修正默认引擎选择 |
| V1 结果下载同源跳转丢失认证 | 每一跳按目标来源设置认证，跨源不携带服务密钥 |
| V1 等待耗尽后仍多发请求 | 等待后再次检查截止时间并限制请求超时 |
| 在线任务异常状态可能无限轮询或抛出字段错误 | 增加可配置轮询上限，验证状态与结果地址 |
| V1 畸形 JSON、空文件或异常输出字段导致底层异常 | 返回明确的协议错误 |
| SDK `skip_translate=True` 返回尚未准备好的结果，无法导出 | 仍执行解析与结果准备，由翻译器跳过模型请求 |
| 相同内容、不同文件名误用同一份缓存结果 | 缓存键加入源文件名 |
| Markdown ZIP 自动模式误选 TXT 工作流 | SDK 与 HTTP 自动识别 ZIP 为 Markdown 工作流 |
| Markdown ZIP 导出名含路径时可能写出临时目录 | ZIP 成员与临时文件只使用文件名 |
| 本地 MinerU 2.x/3.x 后续请求缺少服务密钥 | 同源请求保持认证，外部结果地址不携带服务密钥 |
| JSON 上传忽略损坏的 Base64 字符 | 接受换行，严格拒绝无效字符并返回 400 |
| 释放运行中任务时先删状态，未等取消清理 | 等待后台任务执行清理后再释放状态，最多等待 5 秒 |
| 所有导出都失败却仍显示任务成功 | 标记任务失败并清理临时目录 |

同步、异步流程均有对应协议回归测试；保留旧版 MinerU 回退路径和对外参数。

## 真实服务小样本验证（2026-09-23）

- 使用自制 672 字节、单页、含 `Hello world.` 的 PDF。在线 MinerU 精准解析 API 的 `vlm` 模型成功返回 12 字符 Markdown，包含预期文本。仅提交了这一页。
- 将该 Markdown 交给 SDK 的翻译流程，调用 DeepSeek `deepseek-flash` 一次；输出含中文，应用统计共 211 tokens。请求限制最多一次、最多输出 128 tokens，没有重试。按[官方模型与价格](https://api-docs.deepseek.com/quick_start/pricing/)的峰时最高输出单价粗略上界，211 tokens 对应费用低于 0.0003 美元；实际账单以供应商为准。
- 测试密钥只通过交互进程输入，未写入仓库。该验证覆盖在线 MinerU 与模型服务；本地 MinerU 2.x/3.x/4.x 仍只有模拟协议测试。

## 尚存风险

1. **HTTPS 证书校验被关闭。** `converter_mineru.py`、`converter_mineru_deploy.py` 及 `agents/agent.py` 的 HTTP 客户端存在 `verify=False`。这会降低 Token 与文档传输的安全性。本轮未直接改变该历史行为，以免中断使用自签名证书的既有部署；后续宜提供可信证书配置并逐步启用校验。
2. **离线导出资源需要随发布包检查。** `docutranslate/static/pico.css` 已纳入本次提交；Markdown、JSON、SRT 离线 HTML 导出均引用它。发布构建仍需核对该资源确实进入安装包。
3. **覆盖率及实际部署验证有限。** 单页在线测试无法覆盖复杂排版、较大文件或目标本地服务的可用档位、鉴权配置和解析质量；尤其需在本地环境验证 4.x 对旧版选项的映射结果，详见 `mineru-compatibility.md`。
4. **长时间运行的任务取消。** 释放任务时最多等待 5 秒执行取消后的清理。如果插件或外部调用忽略取消并继续运行，仍可能需要进程结束时的兜底清理。

本记录同时列出模拟测试和一次受请求量限制的真实服务验证。
