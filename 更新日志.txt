v1.7.11版 2026.10.30
特性：
- MCP、SDK 和 HTTP 接口补齐连接、读取、写入、连接池超时及流式策略参数，支持统一配置 HTML 导出的 CDN 和 PPTX 隐藏幻灯片选项
- 新增 HTTP /service/capabilities 和 SDK client.capabilities，统一查询支持的输入格式、工作流及导出能力；MCP 新增任务列表和日志查询，SDK 结果新增统计及附件访问入口
优化：
- 所有工作流共用参数解析、自动路由、格式注册表和工作流工厂，统一 JSON 默认翻译路径、PDF/图片解析引擎选择及各工作流默认配置
- 补齐跨接口契约测试，覆盖全部工作流、参数覆盖、任务状态、格式声明和导出能力，完整本地测试 575 项通过
修复：
- 修复空分隔符、空提示词、显式 false 和 0 被默认配置覆盖，以及自动模式丢失 md2docx_engine=None、无法禁用 DOCX 导出的问题
- 修复 MCP 和 HTTP flat 接口把空字符串形式的未设置选项误当作显式覆盖，导致空 provider/thinking 等参数校验失败、configure_client 后配置被污染的问题；空字符串现在仅对分隔符和自定义提示词生效
- 修复 MCP 取消任务后状态显示为空闲、释放不存在的任务仍报告成功，以及状态查询缺少统计信息的问题
- 修复 MCP 导入软件生成的术语表 CSV 时将 BOM 和 src/dst 表头当作术语的问题
- 修复输入和输出格式声明与实际能力不一致的问题，补齐 TXT/JSON 的 HTML 等导出格式；旧版 DOC/XLS/PPT 文件统一提示先转换为 DOCX/XLSX/PPTX
- 修复包含大量内部跳转链接的 PDF 在 MinerU 在线解析前拆分时长时间停滞的问题
- 修复 macOS 双击应用后没有终端显示访问地址的问题，启动后显示日志和实际 WebUI 地址

v1.7.10版 2026.10.12
特性：
- 支持本地 MinerU 4.x V1 接口及 flash、basic、standard、advanced 解析档位，兼容旧版 2.x/3.x 服务
- 支持本地 MinerU 服务可选鉴权，前端新增密钥输入项，SDK、HTTP、MCP 及工作流支持透传；统一使用 DOCUTRANSLATE_MINERU_DEPLOY_API_KEY 作为环境变量默认值并支持强制覆盖，MCP 配置查询对密钥脱敏
- 支持 MinerU 在线 HTML/HTM 解析，自动选择 MinerU-HTML 模型
优化：
- MinerU 在线解析增加可配置的任务等待上限，完善失败状态、异常响应和下载地址检查，PDF 切片上限调整为 200 页/180 MB（低于服务端 200 MB 上限，留出余量）
- 改进解析缓存的并发访问、容量限制和最近使用淘汰策略，避免不同文件名、服务或账号之间错误复用结果
- 升级前端编码检测库至 jschardet v4，改善短文本及带 BOM 的 UTF-16 术语表编码识别
- 文档预览改用隔离框架，通过消息机制实现同步滚动和打印，避免文档脚本直接访问应用页面
- 分片重试不再受批次规模限制：此前分片少于 15 个时首个错误即放弃重试并回填原文，现在瞬时失败都按 retry 配置重试，且错误计数在批次间重置
- 截断后的续写请求同样按配置重试，重试耗尽才退回部分结果，避免把不完整内容当作成功返回
- Markdown 分段与还原改为完全无损：保留首块缩进、行尾空白和 CRLF，超长代码块切分不再在接缝处插入空行
- 公式与代码处理更保守：行内代码和围栏代码块不再被 $$ 规则改写，HTML 表格内块级公式正确转换，图片地址整段掩码
- 支持 GBK/Big5 等非 UTF-8 的 Markdown，ZIP 内 Markdown 与 CSV 可指定编码，导出保留 BOM 兼容性，首个标题不再因 BOM 丢失
- 服务端：取消任务立即清理临时目录并在启动时清理残留目录，任务记录数量有上限，大文件读写在事件循环外执行，新增可配置的上传大小上限
- 前端：局域网 http 访问下复制日志可用，弹窗滚动锁可正确恢复，队列并发数统一校验，删除任务后立即停止轮询
修复：
- 修复同步和异步模型请求重试时重复追加术语表及提示规则的问题，每次重试保留一份相关术语表及补充纠错提示
- 修复输出截断后续写漏计首轮 token 用量的问题，完整累计首轮及后续请求的输入、缓存命中、输出及推理用量
- 修复批量任务完成后队列不继续、取消或移除任务时并发计数异常，以及旧轮询结果覆盖新任务状态的问题
- 修复按文件自动识别工作流时，参数校验和提交使用错误工作流配置的问题
- 修复 SDK 和 HTTP 自动模式下部分图片、Markdown 和 ZIP 文件的工作流识别及解析引擎选择
- 修复 SDK 跳过翻译时未执行必要的解析和结果初始化，导致无法导出的问题
- 修复跳过翻译时仍触发术语表 AI 生成的问题，保留已有术语表且不发起模型请求
- 补齐 SDK 的 HTML、CSV 和 Markdown 转 DOCX 导出入口，并使可用格式与工作流配置一致
- 修复 SDK 显式设置 md2docx_engine=None 无法禁用 DOCX 导出的问题，支持实例默认配置及单次调用覆盖
- 修复自动 TXT 工作流丢失分段模式参数，以及 MinerU 结束页设为第 1 页时被错误重置的问题
- 修复 MCP Streamable HTTP 使用错误传输方式、术语表生成开关未继承配置，以及配置查询暴露敏感字段的问题
- 修复所有导出格式失败时仍被标记为成功的问题，改善任务取消后的资源清理
- 加强 API 上传内容的 Base64 校验及 Markdown ZIP 导出的文件名处理
- 修复 EPUB 等分段翻译中，模型返回的段落 ID 混用数字和字符串时导致排序报错、翻译中断的问题
- 统一段落 ID 匹配与续传去重逻辑，避免数字 ID 对应的译文丢失或重复覆盖
- 修复 EPUB 译文回填时嵌套 <p> 标签导致的空段落与排版异常
- 修复 EPUB 容器内裸文本与原有段落混排时被吞进同一个 <p>，以及 <br/> 换行、行内图片被拆成独立段落导致的分段与排版异常
- 修复同步接口 /service/flat-translate 默认解析引擎导致 Markdown 上传返回 500 的问题
- 修复参数错误被改写为 500 的问题，现按原始 400/429 返回
- 修复任务取消后临时文件残留、且被当作成功返回的问题
- 修复失败或取消的任务进度仍显示 100% 的问题
- 修复 TXT/SRT/ASS 导出 HTML 未转义文本的问题，并修复 SRT 导出标题为空
- 修复 JSON 导出把文档内容直接注入脚本，以及离线时引用失效 CDN 脚本的问题
- 修复 PPTX 导出隐藏幻灯片开关不生效的问题
- 修复图片链接含括号时掩码被截断、Markdown 转 DOCX 超链接被截断的问题
- 修复缓存数量环境变量取非法值时所有转换失败的问题
- 修复超长单行不受分块上限约束，可能发出远超 chunk_size 的请求的问题
- 修复进度跟踪器递增模式永远到不了 100% 的问题
- 修复若干导出器继承了错误的基类、以及文档中列出但从未生效的配置项
- 修复 SRT 翻译中译文为空的段落被静默删除、后续编号被重排的问题：srt.compose 默认会丢弃空内容条目，现改为空译文按原样写回空内容并保留其时间窗，只有时间轴本身无法表示的条目才会被移除且逐条告警，导出后还会按时间窗回读核对结果完整性
- 修复分段翻译系统提示词中合并示例的引号未转义、示例本身不是合法 JSON 的问题
- 修复 Windows 上注册表把 .js 等扩展名注册为 text/plain 时，前端静态资源以错误 MIME 类型返回、浏览器拒绝执行模块脚本导致界面白屏的问题；静态资源现按扩展名显式给出 Content-Type，不再依赖 mimetypes 与注册表，并同时修正 .mjs、.woff2 等内置表缺失的类型
- 修复 mcp 依赖未设上界、升级到 2.x 后 MCP 静默失效的问题：代码已适配 mcp 2.x 的 MCPServer API（FastMCP 改名、host/port 改为传给 run/sse_app），并要求 mcp>=2.3.0；缺少可用的 mcp 依赖时打包会直接失败，不再产出没有 MCP 却没有提示的安装包
调整：
- 移除 Docling 解析集成及相关参数和依赖，文档解析使用 MinerU 在线或本地服务
- 移除 Windows 完整版构建，保留精简版；macOS 改为分别构建 Apple Silicon 和 Intel 原生安装包
- 分块大小的说明改为 UTF-8 字节（原文档写“字符”，与实际行为不一致）
- DOCUTRANSLATE_PROXY_ENABLED 现在作为 system_proxy_enable 的默认值真正生效
- 新增 DOCUTRANSLATE_TASK_MAX_COUNT、DOCUTRANSLATE_TEMP_CLEANUP_AGE_HOURS、DOCUTRANSLATE_MAX_UPLOAD_MB 配置项，并补齐 SKIP_TRANSLATE 的示例说明
- 测试与工程：测试文件全部纳入版本控制（此前 8 个模块被 .gitignore 排除、从未在 CI 运行），CI 增加覆盖率门禁与随包静态资源一致性检查，清理三代陈旧前端构建产物并移除 frontend/index.html.bak
- 测试与工程：修复 CI 引用了不存在的 setup-uv 版本导致 Windows/macOS 构建在 “Set up job” 阶段就失败的问题；修正 macOS 包标识符占位符，并让 macOS 的 DMG 与 Windows 的 exe 一样随 Release 自动发布
